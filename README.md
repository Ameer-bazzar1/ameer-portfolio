# Ameer Bazzar — hiring brief (static site)

Single-page portfolio summarizing experience, DORAK, and a downloadable CV.

## Run locally

Open `index.html` in a browser, or serve the folder:

```powershell
cd c:\rosca-app\portfolio
python -m http.server 8080
```

Then visit http://localhost:8080

## Deploy

Upload the `portfolio` folder to any static host (GitHub Pages, Netlify, Cloudflare Pages, etc.). Keep `assets/AmeerBazzar_CV.pdf` in place for the download link.

## Customize

- Update copy in `index.html`
- Replace `assets/AmeerBazzar_CV.pdf` when your CV changes
- Add links (LinkedIn, GitHub) in the contact section if you want
